## 구현할 기능 목록

---

### 입력값 추출

- [ ]  입력값을 추출해서 구분자, 숫자로 분리

### 계산 기능

- [ ]  아무것도 입력되지 않은 경우
- [ ]  숫자 1개만 입력된 경우
- [ ]  정수만 입력된 경우
    - 정수값 반환
- [ ]  정수, 소수 섞인 경우
    - 소수값 반환
- [ ]  소수만 입력된 경우
    - 더해서 정수가 되는 경우
    - 더해서 소수가 되는 경우

### 구분자

- [ ]  커스텀 구분자 없이 기본 구문자만 사용하는 경우
- [ ]  커스텀 구분자 사용하는 경우  
  → 양수가 나오기 전까지 커스텀 구분자 입력을 받는다.

### 예외 처리

- [ ]  양수 이외의 숫자 입력 되었을 시 예외 처리   
  → ex. `“0,1,2”` , `“-1,3”`
- [ ]  커스텀 구분자 입력이 정상 완료되지 않았을 경우   
  → ex. `“$\n1,2$3”`, `“//$1,2$3”`, `“$1,2$3”`
- [ ]  커스텀 구분자로 .이 입력된 경우   
  → 소수 입력을 받기 위해서는 커스텀 구분자가 .이 들어오면 안된다.  
  → ex. `“//.\n1.1.3”` : 1.1 + 3 인지, 1 + 1 + 3 인지 모르기 때문
- [ ]  커스텀 구분자로 숫자가 입력된 경우
  → 숫자간에 구분이 되어야 하는데, 숫자가 구분자가 되어버리면 구분이 불가능 하기 때문   
  → ex. `“//3\n13234”` : 1 + 2 + 4 인지, 그냥 1개의 숫자 13234인지 구분 불가

### 출력

- [ ]  계산된 결과를 콘솔에 출력
